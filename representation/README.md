# Representation analyses

This directory contains the representation-level analyses used in the paper.

- `tokenization/` computes token counts, fertility, paired Wilcoxon tests,
  vocabulary sizes, and token-length figures.
- `contextual_asymmetry/` contains the new sentence-level representation
  experiments: semantic-equivalence checks and paired prediction-cost gaps.

See the subdirectory READMEs for setup and commands.
